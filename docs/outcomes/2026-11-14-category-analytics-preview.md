## 建议的信息结构

1. **入口**：历史页第三个 tab「分类统计」，保留现有「周趋势 / 每日明细」。
2. **周期**：周 / 月 / 年三档切换；上方 `‹ 周期标签 ›` 翻页，当前周期不能再往后翻。
3. **概览**：所选周期的分类合计、有记录天数、日均、与上期同期比较。
4. **环形占比**：按分类占比排列；中心显示分类合计；图例显示名称、颜色、百分比。
5. **时间趋势**：每个时间桶一根按分类堆叠的柱子；折线默认是「合计」，点分类 chip 或点环形图图例后切换成该分类；点柱子看当天的分类构成。
6. **每类总时间**：按时间降序；显示总时长、占比、与上期同期变化；停用分类带「已停用」标记。
7. **分类设置**：预览中的可编辑抽屉只用于演示联动；正式版继续使用设置页的分类管理，不在历史页重复做一套。

## 口径（沿用现有数据模型）

观察自现有代码：

- 分类目录在 `settings.categories`，结构为 `{ id, name, archived }`；ID 稳定，改名不改 ID，删除有历史引用时改为停用（`src/core/categories.ts`）。
- `summarizeCycle` 的 `categoryMs` 已把清醒段按分类累计：**补觉单独计入 `napMs`，不进入 `categoryMs`**；`unclassified` 包含未分类段和暂停空档（`src/core/segments.ts`）。
- `buildDayMetrics` 按**起床日**归档；周从周一开始；同一天多条周期全部保留（`src/core/history.ts`）。
- `summarizeDay` 已能把同一天多个周期的 `categoryMs` 相加（`src/core/history.ts`）。

因此建议正式实现直接复用这些函数，不另造一套时间口径：

- **只统计清醒分类**：工作 / 日常 / 自定义 / 未分类；补觉不计入，页面明确标注「补觉另计」。
- **按起床日归属**：与历史页一致；跨午夜睡眠仍归到起床日。
- **周从周一**开始；月按自然月；年按自然年。
- **当天多条周期相加**；进行中的周期按 `nowMs` 截到当前时刻。
- **停用分类保留历史时间**：图表继续显示，名称后加「已停用」；不因为停用而隐藏历史。
- **未知分类 ID**：用 `completeCategories` 补成“待确认分类”占位，避免旧数据/恢复数据里引用丢失。
- **新增分类**：创建后先出现在设置页；第一次有记录后才进入图表和总时间（没有记录不占 0 值行）。
- **比例**：按本周期分类合计计算；预览用最大余数法，图例与总时间的百分比合计为 100%，正式实现沿用。
- **上期比较**：当前周/月/年尚未结束时，与上期**相同已过天数**比较，标签写「同期」；已结束周期与完整上期比较。
- **日均**：按“有记录的天数”算，并在旁边标明记录天数；不把缺失日当 0。

## 图表与交互

- **堆叠柱**：每个时间桶按分类堆叠，堆叠顺序沿用分类目录顺序，颜色稳定。
- **折线**：默认「合计」（等于柱顶）；选择分类后画该分类的时间，折线颜色随分类；图上最后一个点标数值。
- **环形图**：按分类总时间分段，段间留小缝；中心是分类合计；点击图例或趋势 chip 切换折线。
- **周期对比**：周显示 7 个日桶，月显示当月每天（最多 31 个），年显示 12 个月桶；柱状图横轴在窄屏自动减少标签。
- **当前周期**：最后一根柱/最后一个点按已有记录统计，卡片底部提示「当前周期尚未结束」。
- **空状态**：该周期没有记录时显示空状态和“换周期 / 去今日记录”的提示。
- **颜色**：系统分类固定色（工作蓝、日常绿、未分类灰），自定义分类按 ID 稳定映射；改名、停用、排序都不改颜色。正式实现建议固定色 + ID 哈希色相，避免调色板碰撞。
- **可访问性**：颜色不是唯一信息，图例同时给名称和百分比；SVG 带 `role="img"` 和标题，chip 用 `aria-pressed`。
