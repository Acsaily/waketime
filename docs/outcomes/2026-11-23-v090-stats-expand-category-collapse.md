# v0.9.0：统计总览卡展开睡眠比例 + 分类管理大类折叠

来源：用户 2026-11-23 提出两项功能——统计页周/月/年的「总清醒时间」卡片点开可看总睡眠时间与两者比例、再点收起；分类管理里的大类可以收起/展开，减少下滑。

## 实现

### 1. 统计总览卡点击展开

- `CategoryDayTotal` 增加 `sleepMs`（当天所有周期的总睡眠，含补觉）；`CategoryPeriod` 增加 `sleepMs`（本期按起床日归档求和），与清醒时间的归档口径一致。
- 统计页「总清醒时间」卡片整块可点：收起时保持原样并显示「展开」提示与 `▾`；展开后新增「总睡眠时间」「清醒 : 睡眠（百分比）」两行和一条按比例分色的小条，再点收起回原样。
- 比例分母为「本期总清醒 + 本期总睡眠」，四舍五入到整数百分比；没有数据时显示「—」。
- 卡片用 `role="button"` + `aria-expanded`，支持 Enter/空格；展开状态只保存在组件内，切换周/月/年或翻页不会写数据。

### 2. 分类管理大类可折叠

- 有大类的小标签时，大类名称前显示 `▾/▸` 按钮（`aria-expanded` + 可读标签），点一下收起该组全部小标签，再点展开；没有小标签的大类不显示按钮。
- 点「+ 小标签」会自动展开该大类，避免新加的小标签被折叠隐藏。
- 折叠状态只存在当前面板会话里，不写 `data.json`，不改分类顺序或归属。

### 版本

- 0.9.0 / versionCode 12，`APP_VERSION` 同步；schema 仍为 3，升级不迁移数据。
