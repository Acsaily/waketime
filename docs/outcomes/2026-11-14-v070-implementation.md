# v0.7.0 实施记录：统计页 + 睡前时间 + 分段手感

来源：用户 2026-11-14 确认按预览实施，并要求今日页排版与计次位置不变、数据不丢失。
方案：[v070-stats-segment-proposal](2026-11-14-v070-stats-segment-proposal.md)。

## 已实现

### 1. 独立统计页

- 底部导航改为「今日 / 历史 / 统计 / 设置」，`导出` 从导航移除。
- 统计页沿用历史页的左右滑动双面板：`分类统计` / `分类管理`。
- 周 / 月 / 年三种周期，支持上一周期、下一周期（不能进入未来；最早记录之前不可再退）。
- 顶部总清醒时间、已记录天数，与「上周同期 / 上月同期 / 上年同期」比较。
- 环形占比 + 图例：按稳定分类 ID 取色；百分比用最大余数法，合计严格 100%。
- 趋势图：柱状堆叠 + 折线；可切换「合计 / 单分类」，单分类纵轴按该类自己的最大值缩放。
- 分类管理从设置页迁入统计页第二面板；导出与全量备份迁入设置页，原导出能力不变。
- 固定底栏补 `z-index: 20`：长屏手机上统计图表的内部层级会盖住底栏并挡住点击，真机验证时发现并修复（`src/styles-v07.css`）。

### 2. 睡前时间（待分配）

- 新增系统分类 `pre-sleep`，默认名「睡前时间（待分配）」；出现在默认目录、旧数据迁移和备份恢复中。
- 开启第二天 / 原生新周期替换旧周期时，旧周期**最后一次计次后的开放尾段**若为未分类，自动封口在新生效的入睡时刻并标为 `pre-sleep`。
- 只处理最晚开始的开放尾段；已分类尾段、更早的未分类段、补觉都不改。
- 统计中单独成类，可参与合计 / 单分类 / 环形占比；分类管理中只能改名，不能删除、停用、排序。
- 普通段不能主动选睡前时间；原记录仍保留该分类，供分配或继续编辑。
- 统计页「睡前时间待分配」卡片：直接点分类完成分配（`updateSegment`，历史与统计同步），或打开原编辑器细分 / 备注。

### 3. 分段与合并手感

- 拆分改为上下拨动刻度盘：每格 1 分钟，5 分钟加亮、15 分钟加重并显示距开始时长；中心刻度线、滚动吸附、`−1 分 / +1 分`、无障碍滑块兜底。
- 保留多分界点、分段预览、逐段分类与备注、进行中尾段继续计时；原段覆盖范围不变。
- 合并改为右滑确认：滑到 86% 松手执行，未到阈值回弹；同时保留「直接确认合并」按钮。
- 刻度拨动与合并阈值有轻触感/短音；拆分、合并、保存成功后各有一次反馈。
- 计次按钮位置、倒计时卡片、秒表卡片和今日页排版未改；计次成功后增加一次触感/音效与秒表数字轻弹。
- 设置页新增「操作反馈」开关：触感反馈、音效，默认开启，旧数据自动补默认值。

## 数据安全

- schema 仍为 2；新增字段（两个反馈开关）和系统分类都是加法，不重写历史段。
- 旧 `data.json` 读取时自动补齐睡前时间分类，原段 ID、边界、备注、分类不动。
- 睡前时间只在「开启新周期」时标记一次；重复镜像同一原生状态不会重复处理已结束周期。
- 分配只改选中段的 `category`，不改起止时间和备注；总清醒时长不变。
- 同一天重复从「开启新的一天」录入时，周期 id 现在一律走 `uniqueCycleId` 去重（`2026-11-14` → `-2` → `-3`），不会再覆盖已有周期；这是本轮设备测试中发现并修掉的旧数据丢失风险。
- 主数据写入、临时文件、上一份备份与恢复候选逻辑未改。
