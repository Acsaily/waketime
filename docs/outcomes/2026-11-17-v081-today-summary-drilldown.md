# v0.8.1：今日页分类汇总改为「大类 → 细分」下钻

来源：用户 2026-11-17 反馈——今日页分类汇总块把「工作」「工作 / 迭代知我」等所有标签平铺在一起，希望默认只显示大类的时间汇总；点某个大类后转为显示该大类下属细分的时间汇总；返回方式优先「点整个框」而不是多放一个按钮（越简洁越好）。

## 实现

- 新增 `src/components/TodayCategorySummary.tsx`，替换今日页原先直接用的 `CycleSummary`（导出页仍用 `CycleSummary`，保持完整分类路径的文本汇总不变）。
- 默认（大类层）：按 `categories` 目录顺序只列顶级分类，时间 = 该大类自身 + 全部下属小标签之和；「未分类」即使 0m 也保留，其余 0m 隐藏，补觉（`sleep`）不计入。
- 大类名下有小标签时，名称后显示 `›`，整行是按钮；点击进入该大类的细分层。
- 细分层：第一行是「大类名（未细分）」（仅当该大类自身有直接时间），其后按目录顺序列出有时间的小标签；顶部一行面包屑「‹ 大类名 · 点任意处返回」。
- 返回：细分层下整块都可点（`role="button"` + Enter/空格），点框内任意位置回到大类层，不额外占按钮位置。
- 数据与文案：层级聚合纯函数 `summaryRows()` 放在 `src/core/categoryStats.ts`，与统计页的 `categoryEntries` 口径一致（大类含小标签、未细分单列），但按目录顺序排列，时间变动时行序不跳动。
- 版本：0.8.1 / versionCode 11；`APP_VERSION` 同步为 0.8.1。schema 不变（仍为 3），升级不迁移数据。
